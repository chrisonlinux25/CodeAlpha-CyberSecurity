# CodeAlpha Cybersecurity Internship

This repository contains the projects I completed during my **Cybersecurity Internship at CodeAlpha**. The projects provided hands-on experience in cybersecurity, network security, phishing awareness, secure coding, and intrusion detection.

## Projects

### 1. Basic Network Sniffer

A Python-based network sniffer designed to capture and analyze network packets. The project focuses on understanding network traffic, protocols, source and destination IP addresses, ports, and packet payloads.

**Technologies:** Python, Scapy

### 2. Phishing Awareness Training

An educational cybersecurity awareness project focused on helping users recognize phishing emails, fake websites, and social engineering techniques.

The project includes a presentation, real-world examples, prevention techniques, and an interactive phishing awareness quiz.

**Technologies:** Google Forms, Presentation

### 3. Secure Coding Review

A security-focused code review project involving the identification and analysis of vulnerabilities in an application. The project documents security findings, explains potential risks, and provides recommendations for remediation and secure coding practices.

**Focus:** Vulnerability Assessment, Secure Coding, Static Analysis

### 4. Network Intrusion Detection System

A network-based intrusion detection project designed to monitor network traffic and identify suspicious activity using detection rules and security alerts.

**Technologies:** Suricata/Snort, Network Monitoring, Python
